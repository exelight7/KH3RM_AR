# تحسين واجهة README

round: README-POLISH

التاريخ: 13 أكتوبر 2026.

## التغييرات

- عنوان مركزي وصورة المثبت، وروابط تنقل وتنزيل مباشرة لـWindows وLinux.
- اختصار التثبيت إلى ثلاث خطوات، وطي التثبيت اليدوي في قسم قابل للفتح.
- حذف الشكر وإخلاء المسؤولية والكلام عن الشركات من README بطلب صاحب المشروع.
- اختصار حالة المشروع مع توضيح الفرق بين ترجمة المصدر وحزمة BUILD-7 المنشورة.
- الإبقاء على خريطة Graphify التفاعلية في قسم مستقل أسفل الصفحة.
- تحديث قالب التوليد حتى يبقى التصميم عند النشر اللاحق.

## نطاق العمل

تغيير توثيق فقط؛ لا تعديل للترجمات أو ملفات اللعبة أو المثبت أو إعدادات Graphify وObsidian. بقيت ملفات الحقوق المنفصلة كما هي. حفظت نسخة محلية من README والقالب قبل التغيير.

## الفحص

توليد النسخة العامة وفحص محتواها قبل النشر. لم تشغل اختبارات برمجية لأن العمل يقتصر على التوثيق.
