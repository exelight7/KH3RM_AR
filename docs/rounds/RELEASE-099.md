# RELEASE-099 — 2026-10-16

طلب المالك: جمع ملفات المثبت في حزمة واحدة للتنزيل، إصدار 0.9.9، وتقرير مفصل لكلود يشرح معالجة إنذار الحماية.

## تنفيذ الإصدار

- التنزيل الأساسي على Windows هو ZIP يضم البرنامج وجميع مكتباته و.NET، وعلى Linux أرشيف tar.gz للمجلد الكامل.
- القيم: SelfContained=true، PublishSingleFile=false، EnableCompressionInSingleFile=false، IncludeNativeLibrariesForSelfExtract=false. أزيلت رموز التصحيح من البناء المنشور.
- بقيت حزمتا BUILD-18 وIMAGES-MASS11 مضمّنتين وببصمتيهما السابقتين. التغيير الوحيد في Core.cs هو رقم الإصدار؛ فحص SHA والتثبيت المرحلي وخيارات الصور كما هي.
- تحديث SDK البناء إلى 8.0.426 وruntime المضمن إلى 8.0.32، مع تحقق SHA512 لتنزيل SDK الرسمي. أرفقت رخصة Plex داخل الحزمتين.
- نجحت فحوص Windows الـ37، ثم نجحت بعد فك ZIP. تحققت جميع ملفات الأرشيفين بالبصمات، وصلاحية التشغيل 0755 للملف الرئيسي على Linux.
- حافظ README على تصميمه، مع تحديث رقم الإصدار والرابط وطريقة التشغيل داخل خلية التنزيل نفسها.

## دليل الحماية

لقطة المالك تعرض 0/70 وبصمة `8a56394eeb689b8126785740b6ce08f586c5bbdf90238fb0d6a3d1f4cda5b665`؛ وهي بصمة ملف التشغيل الصغير في تجربة المجلد السابقة. الاسم المعروض في موقع الفحص لا يحدد نوع الملف؛ المطابقة اعتمدت على SHA256.

هذه النتيجة لا تشمل كل مكتبات المجلد ولا أرشيف إصدار 0.9.9. سبب قاعدة Zillya السابقة غير مثبت، والتغليف الجديد يزيل سببي الاشتباه البنيويين المقيسين: الـoverlay الكبير والاستخراج المؤقت لمكتبات bundle. لا توقيع ولا استثناءات حماية ولا رفع عينات إضافية ضمن الجولة. Defender المحلي يعيد Invalid class.

## الحدود

لم يشغّل المنفذ اللعبة أو يغيّر تثبيتها أو ~mods، ولم يقرأ مصدر المفتاح. Linux مبني لكنه غير مجرب على Linux حقيقي. 1.0.0 مقفل. تقرير كلود التفصيلي وسجلات البناء محفوظة محليا؛ لا تنشر ملفات التحقيق الخاصة أو graphify-out.
