## Open publishing decision
`translation\` and `review\` contain the game's English text (EN column), which is Square Enix copyright. Before any public push decide: publish AR only (strip EN), keep those folders private/ignored, or publish as is. They are self-contained folders so they are easy to exclude (add to `.gitignore`). Also open: license (`LICENSE_TODO.md`).
