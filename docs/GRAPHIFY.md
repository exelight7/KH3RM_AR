# خريطة المشروع — Graphify

اعتمد صاحب المشروع Graphify في 13 أكتوبر 2026 بوصفه نقطة تنقل للمشروع كله، مع قسم مستقل للخريطة في أسفل README. تعليمات الاستخدام محفوظة في `AGENTS.md` و`CLAUDE.md`، والتكامل المحلي مهيأ للجلستين.

## فتح الخريطة

- [الخريطة المنشورة التفاعلية](https://exelight7.github.io/KH3RM_AR/graph/).
- [ملف بيانات خريطة المستودع العام](graph/graph.json).
- داخل المشروع المحلي: `graphify-out/graph.html` يجمع النسخة المحلية ونسخة GitHub؛ `graphify-out/graph.json` خريطة النسخة المحلية، و`cross-repo-graph.json` بيانات الخريطة المدمجة.
- [تقارير دفعات المراجعة](rounds/).

## العمل مع Claude وCodex

ابدأ بـ `PROJECT_MAP.md` ثم اسأل الخريطة عن الملفات المعنية. مثال: `graphify query "translation pipeline"`. عند العمل من نسخة المستودع العام استخدم `--graph docs/graph/graph.json`. بعد تعديل الشفرة حدّث الخريطة المحلية بـ `graphify update .`؛ الوثائق تحتاج تحديثا دلاليا مستقلا عندما يتغير مضمونها.

تقارير المراجعة تبقى Markdown. HTML وSVG معتمدان للخريطة فقط بطلب صاحب المشروع، ويستطيع README عرض البطاقة المرئية وفتح الخريطة على GitHub Pages.

## حدود النشر

النسخة المحلية قد تتضمن سياقا من المصدر الإنجليزي، ولذلك تبقى داخل المشروع الخاص. النسخة المنشورة مشتقة من خريطة المستودع العام؛ تحفظ أسماء الأدوات ومسارات الملفات والعلاقات، وتحذف نصوص المصدر المطولة والخصائص غير اللازمة. لا تنشر سجلات المقارنة الخاصة أو ملفات اللعبة أو المفاتيح.

الخريطة وسيلة تنقل، وليست دليلا على أن كل علاقة صحيحة أو أن الترجمة اختبرت بصريا. فحص الاستخراج السابق سجل أطرافا غير مكتملة وعلاقات مدمجة، والتفاصيل في تقارير `graphify-out` المحلية. نتائج مراجعة النصوص والتحقق داخل اللعبة تسجل منفصلة.
