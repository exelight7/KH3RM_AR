# FAQ

## العربية (Arabic)
- **كيف أثبت?** شغل المثبت واللعبة مغلقة.
- **SmartScreen:** يظهر تحدير لأن المثبت غير موقع: اضغط More info ثم Run anyway.
- **Steam:** تحديثات Steam قد تعيد ضبت أو تكسر المودات: أعد تشغيل المثبت.
- **انهيار:** لا تحذف ملفات اللعبة. جرب أولا إزالة حزمتنا (`REMOVE_AR.bat`). تقارىر من المجتمع تقول إن بعض المودات تحتاج إلى اسم ملف ينتهي ب `_0_P` في النسكة الحالية; لم نتهقق من ذلك.
- **كيف أبلغ?** سطر واحد (انظر دليل المختبر) أو قالب البلاغ في GitHub Issues.
- **الحقوق:** ترجمة معجبين غير رسمية, لا علاقة لها ب Square Enix أو Disney. الخط وحزمة الصور نسخ معدلة من ملفات اللعبة وتستعمل على مسؤولية المستخدم.
- **Steam / Epic:** يعمل مع صتeaم و Epic. المثبت يبحث عن مجلد اللعبة; واختر المجلد يدويا إن لم يجده (عةic جرب على ملفات وهمية فقط).

## English
- **Install:** run the installer with the game closed.
- **SmartScreen:** the installer is unsigned; click More info, then Run anyway.
- **Steam updates** may reset or break mods: re-run the installer.
- **Crashes:** do not delete game files. First try removing our pak (`REMOVE_AR.bat`). Unverified community reports say some mods on the current build need a pak name ending in `_0_P`; we have not tested this.
- **Report:** one line (see `docs/TESTER_GUIDE.md`) or the bug report form in GitHub Issues.
- **Rights:** unofficial fan translation, not affiliated with Square Enix or Disney. The font and the optional images pack are modified copies of game files, used at the user's own responsibility.
- **Steam vs Epic:** both work; the installer looks for the game folder, pick it by hand if it is not found (Epic detection is tested on fake files only).
