# قائمة فحص الصور — الجولة 2

1. في سان فرانسوكيو (فلاش تريسر) وآرنديل (المنزلق المتجمد): هل كلمات «استعد / انطلق! / انتهى!» وجدول النتائج مقروءة؟ (نعم/لا)
2. في المطعم (لعبة الطبخ) ومملكة كورونا (الرقصة): هل «جيد / ممتاز / ابدأ! / انتهى الوقت!» مقروءة؟ (نعم/لا)
3. في معركة السفن (الكاريبي): هل كلمة «الهدف» على اللافتة مقروءة بلا بقعة ظاهرة؟ (نعم/لا)
4. تحت الماء: هل عداد الهواء يقول «الهواء»؟ (نعم/لا)
5. في غابة المئة فدان وصندوق الألعاب (فيروم ريكس): هل كل شيء سليم، لا صور مكسورة أو سوداء؟ (نعم/لا)

العب بشكل طبيعي، وأرسل صورة شاشة فقط إذا بدا شيء خاطئ.
